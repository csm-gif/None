Methodology

Our measurement rules

These five rules apply to every project, large or small.

  1. Baseline first

    We record the key numbers before changing anything.

  2. Check the tracking

    If the data is wrong, every decision based on it is wrong too.

  3. Log every change

    Each change gets a date, so we can match it to results.

  4. Compare like with like

    We compare equal periods and allow for seasonal patterns.

  5. Report what didn't work

    We report a failed test as clearly as a successful one.
